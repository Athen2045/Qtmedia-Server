# Unified Interactive Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a single `main.bat` launcher with an interactive menu for search, download, inspection, help, and exit.

**Architecture:** `main.py` is the root launcher and delegates to `private_search.cli.interactive_menu`. The menu calls existing search, inspection, and download interfaces; it does not duplicate network or yt-dlp behavior. `main.bat` selects the project virtual-environment interpreter automatically.

**Tech Stack:** Python 3.11+, Typer, Rich, yt-dlp, Windows batch scripting, pytest.

## Global Constraints

- `main.bat` is the primary interactive launcher.
- The user must not manually activate `.venv` to use the menu.
- Option 3 inspects metadata only and never downloads.
- Existing CLI commands and compatibility launchers remain available.
- Existing user artifacts and unrelated worktree changes remain untouched.
